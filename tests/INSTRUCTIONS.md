# Name Game Tag System

The Name Game now supports tagging students and practicing with specific groups. Here's how it works:

## Tag System Features

- **Create tags**: Create categories like "Section-A", "Front Row", "Difficult Names", etc.
- **Tag students**: Assign one or more tags to each student
- **Filter by tag**: Filter the student list by tag in the management screen
- **Practice with tags**: Choose a specific tag group when starting a game
- **Performance filtering**: View performance statistics filtered by tag

## How to Use

### Creating and Managing Tags

1. Go to the "Manage Students" section
2. Click on the "Tags" tab
3. Create new tags using the form at the top
4. View all existing tags with their stats (number of students, etc.)
5. Delete tags you no longer need

### Tagging Students

1. When adding a new student, you can specify tags in the "Tags" field (comma-separated)
2. For existing students, edit the student and update their tags

### Practicing with Specific Groups

1. Start a new game
2. In the game options, select a tag from the "Select Tag" dropdown
3. Only students with that tag will be included in the game

### Tag-Based Performance Stats

1. View Performance Stats
2. Use the tag filter dropdown to see stats for specific student groups

## Implementation Details

The tag system maintains a consistent student performance database across all tags. This allows you to:
1. Track overall performance for each student
2. Practice with specific groups when needed
3. See how different groups compare in performance

## Tips

- Create tags for different classes, difficulty levels, or learning objectives
- Use the tag filter to quickly find specific students in large datasets
- Practice with smaller, focused groups to build familiarity before trying the full student list
